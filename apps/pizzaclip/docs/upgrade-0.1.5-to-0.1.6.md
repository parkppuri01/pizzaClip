# pizzaClip 0.1.5 → 0.1.6 업그레이드 안내

랜딩페이지 / README / Settings 안내문 / Release Notes 어디에 붙여도 되는 한국어 본문입니다.

## 0.1.6 에서 바뀐 것

- **Apple Developer ID 정식 서명** + Apple notarize → 더 이상 "확인되지 않은 개발자" 경고 없음
- 메뉴바 피자 아이콘 단계 정리 (총 10단계, 슬라이스 1~7개 / 피자박스 / 박스 쌓임)
- 클립보드 **"피자"** 도 🍕 이스터에그 발동 (기존 "pizza" 와 동일하게 정확 매치)
- 우⌘ 한/영 토글 권한 자동 복구 — 권한 부여하는 순간 우⌘ 가 바로 작동 (Settings 에서 체크박스 다시 토글할 필요 없음)
- 코드 서명 방식 업그레이드에 따른 **권한 1회 재승인** 필요 (아래 안내)

## 설치 (신규 사용자)

1. [pizzaClip-0.1.6.dmg 다운로드](#) 클릭
2. 더블클릭으로 DMG 마운트 (경고 없이 바로 열림)
3. pizzaClip 아이콘을 Applications 폴더로 드래그
4. Launchpad / Spotlight 에서 pizzaClip 실행
5. 처음 실행 시 macOS 가 손쉬운 사용 권한 요청 → 허용

끝. 메뉴바에 피자 아이콘이 뜨면 정상.

## 업그레이드 (기존 0.1.5 사용자)

> ⚠️ **권한 재승인이 1회 필요합니다.** 이번 한 번만이고, 이후 버전부터는 자동으로 유지됩니다.

### 왜 필요한가요?

0.1.6 에서 코드 서명 방식을 **자체서명 → Apple Developer ID** 로 업그레이드했습니다. macOS 보안 정책상 시스템이 pizzaClip 을 "새로운 앱" 으로 인식하므로 손쉬운 사용 권한을 다시 부여해야 합니다.

### 단계

1. **기존 pizzaClip 종료**
   - 메뉴바 피자 아이콘 우클릭 → Quit pizzaClip
2. **새 버전 설치**
   - [pizzaClip-0.1.6.dmg 다운로드](#) → 마운트 → Applications 폴더에 덮어쓰기
3. **pizzaClip 실행**
   - 처음 실행 시 안내 다이얼로그가 뜹니다 → "시스템 설정 열기" 클릭
4. **시스템 설정에서 권한 재부여**
   - 손쉬운 사용 목록에서 기존 **pizzaClip 항목 선택** → 왼쪽 아래 **−** 버튼으로 제거
   - **+** 버튼으로 `/Applications/pizzaClip.app` 다시 추가 → 토글 **ON**
   - (또는 새로 추가하는 다이얼로그가 자동으로 뜨면 거기서 허용)
5. **검증**
   - 메뉴바 피자 아이콘 클릭 → 팝업 정상 작동
   - 우⌘ 한/영 토글 사용 중이라면 → 자동으로 다시 작동 (체크박스 토글 불필요)

### 잘 안 되시면

| 증상 | 해결 |
|---|---|
| ⌘V 페이스트가 안 됨 | 손쉬운 사용 권한 미부여 — 위 4단계 확인 |
| 우⌘ 한/영 토글이 안 됨 | 위 4단계 후 2초 기다리면 자동 복구. 안 되면 Settings → Shortcuts → "Input source" 체크박스 OFF → ON |
| "확인되지 않은 개발자" 경고가 뜸 | 0.1.6 는 notarize 되어 있어서 안 떠야 정상. 만약 뜬다면 다운로드한 DMG 가 손상됐을 가능성 — 다시 다운로드 |
